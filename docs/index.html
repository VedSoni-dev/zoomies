What works

Record in the tab

A screen, window or browser tab, with tab audio and optional mic. Chrome, Edge and Firefox on any OS.

Drop a video

Recordings from QuickTime, OBS, Game Bar, Loom or a phone get the same treatment.

Auto-zoom

Finds where a small part of the screen changes (typing, clicks, menus) and places a zoom there. Scrolls and page loads don't trigger one.

Spring camera

Glides in, holds and eases out. Preview and export land on the exact same frames.

Edit every zoom

Drag, resize, delete, click the preview to add one, plus a strength slider.

Framing

Nine backgrounds, a solid colour or your image; padding, corners, shadow; 16:9, 1:1, 9:16.

MP4 in the tab

1080p or 720p, 30 or 60 fps, with sound. A MediaRecorder fallback where WebCodecs is missing.

Stays on your device

Projects live in your browser. The video is never uploaded.

Not yet

  • Zooms follow what changes on screen, not your real clicks: a web page can't see the mouse outside its own tab.
  • No cursor smoothing, click ripples or motion blur.
  • No webcam bubble, captions, GIF export, trimming or speed-ups.
  • Screen recording needs a desktop browser (phones can still drop a video). Clips up to 15 minutes.

Run it yourself

git clone https://github.com/VedSoni-dev/zoomies
cd zoomies && npm install && npm run dev

The app at /app opens with no sign-in for now; the publik listing is coming soon. The optional post writer runs on publik API or your own key.
